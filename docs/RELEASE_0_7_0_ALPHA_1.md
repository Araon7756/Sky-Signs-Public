## 已知限制与未验证范围

- 真实旧玩家世界的现有迁移证据限定于 WEATHER v1 自动世界；v0 自动／手动和 v1 手动真实世界仍未验证。合成 NBT/磁盘 fixture 不代替真实世界验收。升级前备份世界；未来／损坏数据保护仅限模组自有载荷，不承诺整个世界降级安全。
- 旧客户端英文 fallback、连接及通道互通未验证；新版中英文界面结果不能替代旧客户端测试。
- 多人／专用服务端未验证；单人集成测试不证明多人一致性。
- P1 性能回退对照与长期可靠性未验证；连续十周期和短时单人测试不构成长时保证。
- Iris／Photon／整合包仅有特定硬件与组合的有限证据，不能宣称完整兼容。光影开关的雪可见度差异仍在，最小无 Sky Signs 环境已有相关复现，根因未定位。最新动态采集结论仍为“本次有限时窗未捕获，动态反馈仍未验证；原反馈继续保留，根因未定位”。
- Photon 历史窗口缩放／闪电黑屏没有根因修复结论；关闭闪光或重载仅有有限缓解证据。
- 测试框架 #49 补丁需显式开启，仅供测试实例，不进入正式 JAR。原生方格区块等待仍未修复；#48 实际发送集合就绪不能写成原生等待修复。

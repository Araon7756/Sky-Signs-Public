# 0.7.0-alpha.1：P1 阶段预览候选（尚未发布）

维护者于 2026-10-11 确认按 P1 限定范围准备预发布，并选定版本号 `0.7.0-alpha.1`。本分支准备候选与验收材料，不创建标签或 Release。最近已发布版本仍为 0.6.0-beta.9。

## 本次范围

Minecraft Java 1.21.10 / Fabric / Java 21。P1 已合并的服务端天气计划保持 CLEAR、RAIN、STORM 三态，在同一游戏 tick 计划中提供前兆、切换与过渡／缓和；气压、湿度天气基值和自动风目标区间连续接入。原版 `/weather` 时长、自然循环、暂停恢复和睡眠行为保留各自语义；WEATHER 数据迁移为 2，WIND/METER 结构版本保持 1。

这是 P1 阶段预览，不包含设计中的环境风粒子、风声、统一设置页面或协议 v3；不是完整 0.7 功能交付。Iris 光影启用时停用降水倾斜仍属预期行为。

候选分支基于 main `db235b143948b1aaac04477c2bfa953dd692db38`，本次仅修改版本元数据与说明、补充证据，不修改 Java、资源模型、依赖或实际功能。版本号用于构建/发行识别，不能替代存档数据结构版本。

## 已知限制与未验证范围

- 真实旧玩家世界的现有迁移证据限定于 WEATHER v1 自动世界；v0 自动／手动和 v1 手动真实世界仍未验证。合成 NBT/磁盘 fixture 不代替真实世界验收。升级前备份世界；未来／损坏数据保护仅限模组自有载荷，不承诺整个世界降级安全。
- 旧客户端英文 fallback、连接及通道互通未验证；新版中英文界面结果不能替代旧客户端测试。
- 多人／专用服务端未验证；单人集成测试不证明多人一致性。
- P1 性能回退对照与长期可靠性未验证；连续十周期和短时单人测试不构成长时保证。
- Iris／Photon／整合包仅有特定硬件与组合的有限证据，不能宣称完整兼容。光影开关的雪可见度差异仍在，最小无 Sky Signs 环境已有相关复现，根因未定位。最新动态采集结论仍为“本次有限时窗未捕获，动态反馈仍未验证；原反馈继续保留，根因未定位”。
- Photon 历史窗口缩放／闪电黑屏没有根因修复结论；关闭闪光或重载仅有有限缓解证据。
- 测试框架 #49 补丁需显式开启，仅供测试实例，不进入正式 JAR。原生方格区块等待仍未修复；#48 实际发送集合就绪不能写成原生等待修复。

## 实际目视范围与结果

本次没有连续播放能力，也没有原尺寸逐张目视全部视频帧。采用全帧技术核验，加每 0.5 秒取实际捕获帧的加密目视采样：露天 360、顶棚 180 张，覆盖六段各自完整有效时间范围；查看新生成的 18 张联系表。另查看最低值前后各两帧、全部四处间隙邻帧及四次手动切换附近，共 93 张额外图像、7 张邻帧表；总计 633 个不同原视频帧的缩略表示。六个最低值中心帧另以 1280×720 单帧直接查看。收据列出全部选中帧号和选择规则；派生图不改写视频，也没有插帧。

露天三个状态的观察：开前/再开时上方、山坡前仍有明显雪，中间远景带雪较难辨认；关闭后紫色雪点与黑色背景的对比更清楚。全部六个最低值邻帧中，没有确认能建立“正常→消失/明显变淡→返回”的自发事件链。顶棚三个状态近处密集雪点均大幅减少，背景外观随光影开关改变；顶棚影响天空光和阴影，不能作为纯深度单变量对照。手动切换附近的背景/雪颜色变化与记录时刻相邻，按切换排除，不算自发事件。

这仍是受限目视观察：0.5 秒采样和缩略图不能否定更短、局部或较弱事件；相邻帧展示也不是个体雪花追踪。没有据此判定原始事件同一性、几何遮挡或 GPU 根因。

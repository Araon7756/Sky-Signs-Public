## Photon 降雪可见度控制组（2026-10-10，根因未定位）

实际被测 main `3c60a8b3a2e378b1076c0a6a89335de5c839433b` 的七组隔离单人证据（原始证据保留于 Private 档案） 表明：全新雪原场景中，即使没有 Sky Signs、CoolRain 或 Distant Horizons，仅 Fabric API／Sodium／Iris／Photon 也会出现远窗口外雪花在 Photon 开启时几乎不可见、关闭后明显出现、再次开启重复的差异。加入上述模组，或分别改变 Photon 的降水倾斜、雪透明度和主世界雾强度，差异均仍在。

这是本机具体版本与场景下的已复现可见度差异，尚未确定 Photon／Iris／Sodium／驱动的具体责任或底层机制，也未确认与用户原始山体“遮挡不正常”反馈完全同一。实心墙与手持石头有限场景未见明确白色雪花穿墙或覆盖手持物，不据此关闭反馈或宣称全场景通过。此降雪记录与后文窗口缩放闪电黑屏记录分别保留，不推断同一根因；本次共享没有修复功能或新运行验证。其他发布前缺口见 [P1_RELEASE_CHECKLIST.md](P1_RELEASE_CHECKLIST.md)。

[Cloud 只读核查报告](SNOW_RENDER_AUDIT.md) 固定核查 main `28dbe0cf`，生产输入与 Local 被测 `3c60a8b3` 一致。**可见度降低不等于遮挡关系错误**：本轮未明确具体雪花相对遮挡物的预期前后关系，不能据此确认深度缓冲异常或关闭原始山体反馈。源码中的直接降水介入是上沿顶点 X/Z 偏移，Iris API 报告启用光影后返回零；实际逐帧状态未观测。未发现本模组自定义深度／混合／雾／雪透明度渲染路径，不扩大为所有渲染问题都与本模组无关。继续保留“最小环境可复现、根因未定位、与原反馈同一性未验证”。

## 历史故障：避免重复误诊

- **Photon v1.3b 闪电黑屏**：历史实测曾出现。当前 Iris 光影启用时停用本模组降水偏移；这是兼容策略，不是修复 Photon 源码，也不代表所有渲染组合已通过。复现时记录准确版本和光影开关，先区分雨滴倾斜与闪电表现。
- **仪表顶盖共面／指针和库存不一致**：历史多次修正，beta.7 候选截图发现库存朝向问题并修正，现已合并和发布；候选截图检查与发布回归不代表整合包所有视角均无问题。
- **第二客户端原生崩溃**：alpha.3 两次 GLFW `EXCEPTION_ACCESS_VIOLATION`，没有进入联机验证；原因未确认，已停止临时监听。旧本机日志不在 Git，不作为 Cloud 可复现输入。
- **Just Enough Characters 类转换异常**：beta.4 历史说明记录需要单独排查，没有证据证明由本模组造成或已修复。需用户提供新报告及环境，不盲改天气代码。
- **测试目录文件锁**：beta.6 记录一次重叠启动失败，顺序复测通过；避免并行使用同一客户端运行目录，不通过删除玩家存档解决。

## Client GameTest 同步器诊断（2026-10-02）

两份历史自然失败的完整堆栈均定位到 `NetworkSynchronizer.waitForPacketHandlers` 的十秒条件等待超时分支，分别发生在模型展示期间和世界退出阶段。无等待保护的独立受控复现确认同版本框架存在丢失通知竞态：包与任务队列已为零，仍等待约十秒后 invalid。但历史日志没有首次 invalid 的计数和事件，尚不能认定该竞态是历史故障的唯一根因，见 完整诊断（原始证据保留于 Private 档案）。

加载/不加载 Sky Signs 的固定生命周期对照共 40 次世界会话完成；随后调用未修改的原有模型方法，5 个周期、15 次世界会话及 20 个方向展示完成。两轮均未自然复现 invalid，不能写成已修复或完整回归通过，也不作为恢复正式性能采样的依据。后续仍需捕获历史出错路径的首次状态。范围、差异和附件见 生命周期对照（原始证据保留于 Private 档案） 与 模型方法专项（原始证据保留于 Private 档案）。未改产品/原有测试源码、依赖或同步机制；上游问题草稿尚未向 Fabric 提交。
